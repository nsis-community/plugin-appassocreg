## Installation

Download the installer or archive from the [Releases page](https://github.com/nsis-community/plugin-appassocreg/releases).

If you downloaded the zip archive, extract it into your NSIS folder: it adds `AppAssocReg.dll` to `Plugins/<variant>/`.
